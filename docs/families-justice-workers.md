# 家庭、司法与模拟线程

本次按 **24 位成年 NPC、较多戏剧冲突** 实现。保留原来 8 位居民全部存档，加入医生、教师、护林员、警务员、乐师、陶艺师、农夫、厨师、矿工、收购商、船员、裁缝、教练、植物学者、记者和钟表匠。每位都有独立人设、秘密、关系和四份可编辑文档。新增三对已有交往背景的情侣和一组矿石货款纠纷；没有预先强制结婚或杀人。

## 婚姻与孩子

- Jev 在行动候选中决定是否讨论婚姻，再分别读取双方自己的上下文作出意愿判断。候选需要双方成年、在世、自由，互为恋人，无配偶，双向好感 ≥65、信任 ≥60、吸引 ≥35、怨恨 <25。双方明确同意且置信度 ≥0.5 后提交婚姻，记录公开婚讯和个人长期承诺。
- 双方的秘密、整份记忆不会交给另一方。意愿结果还要验证角色版本、在世与拘押状态。编辑文档、死亡等变化会使旧结果失效。
- 婚后见面讨论育儿，每对每天至多一次 20% 机会；仍需双方独立同意。等待 2 个游戏日后加入一个孩子。使用加速、抽象家庭机制，不模拟妊娠医学或现实刑法。
- 每位家长最多 2 个孩子，全镇累计角色上限 48（含留档角色）。只有一项待出生计划可同时涉及同一位家长。照护条件因死亡、监禁等改变时取消原计划，不凭空加入无照护者的孩子。
- 新孩子建立唯一 ID、双向亲子关系、独立记忆和秘密文档，按较小的像素角色渲染。孩子跟随可用家长，或由教师 / 镇民照护，不参与成人恋爱、生产、打猎或凶案。
- 当前儿童保持幼年阶段，日常照护与监内作息使用规则，不为每个步伐调用模型。玩家仍可与可接近的孩子交谈。当前婚姻限 NPC 之间，未加入玩家婚姻、离婚、再婚、自然衰老或完整代际成长。

## 冲突、调查和服刑

`murder → investigating / unresolved → sentenced → released`

- 成年自由居民中，具有激烈性格、对目标怨恨 ≥85 且相距 ≤5 格，才可能获得致命冲突候选。每位每 4 小时至多一次 25% 候选检查，Jev 仍可选择等待、调解、离开或其他行动。全镇最多每日一起；自由成年人不多于 12 人时不再生成。孩子不作为行凶者或受害者。
- 事件无血腥表现。受害者停止行动、取消户外活动 / 对话 / 约定，清除旧决策并保留档案。附近实际目击者才得到目击记忆；其他居民只收到已公开的案件消息。
- 案件最早 3 小时后核查；有现场记录和独立证词 / 交叉核实物证才能判刑。每轮 65% 机会获得核实物证，证据不足则一天后继续调查。依据是模拟世界生成的证据，不读凶手私有记忆、不把模型说法当司法事实。
- 公开快照不发送未判明的行凶者 ID 和证词详情；定罪后通过公开事件公告身份。观察者仍能查看每个人的私人记忆。
- 模拟刑期为 5 个游戏日。角色入监后在围墙内休息、用餐、放风阅读，无法工作、约会、外出、接受玩家交谈 / 赠礼；期满在司法所门外释放。程序保存案件状态，重复 tick 或读档不会重复判刑、生育、释放。
- Three.js 中加入石墙、角楼、铁栏、床铺、院落、桌椅和夜灯。地图「司法所 / 监狱」按钮可直接查看，生活簿可导航前往门口。

## 线程与状态归属

```text
浏览器主线程：React、Three.js、输入与镜头
              ↕ HTTP / WebSocket（每 500 ms 快照）
Node 主线程：本地鉴权、静态资源、连接、RPC 转发
              ↕ worker_threads 消息
模拟 Worker：World.tick、寻路、Jev / DeepSeek、SQLite、Markdown
```

`server/index.ts` 启动真正的 Node Worker，而不是仅改成 async 或 Promise。数据库、token 预留和模型请求仅由 Worker 持有。主线程缓存已投影的公开 / 观察者快照，转发带 ID 的请求；Worker 复用原 API 验证、幂等和预算逻辑，内部路由不监听端口。浏览器继续独立 `requestAnimationFrame` 插值绘制，没有将 Three.js 搬到 OffscreenCanvas。

24 人按轮转调度获得执行机会，模型任务继续最多 3 组并发。暂停、预算用尽停止新决策与所有生活事件，已发出请求继续结算；结果在恢复时重新检查。正常关闭先停止调度、等待请求结算，再保存原运行标志，重启后从保存的游戏时间继续，不补算停机时间；原来暂停的世界仍保持暂停。Worker 异常会断开实时连接并报错，不自动反复重启模型请求。

保存格式升级为 v3。v1/v2 首次升级前自动归档原世界；重复升级不重新加入居民或改写旧关系。恢复旧存档会补齐新文档。已消耗 token 和未知预留保持原账本，不随世界读档回退。

## 操作与验证

左侧「家庭与司法」打开生活簿；事件筛选新增「婚姻与孩子」「冲突与司法」。人物页显示配偶、孩子、服刑或已故状态。右侧关系页标识配偶、家长和孩子。

- `npm test`：37 项通过，包含新增独立意愿、文档 / 快照隔离、暂停 / 重启后只生育一次、死亡取消行为、证据不足不拘押、监内路径、刑满释放，以及真实 Worker 的鉴权 / 存档 / 预算测试。
- `npm run build`：TypeScript 与生产构建通过。
- `npm run check:simulation`：隔离的 24 人规则世界连续 3 天，499 条事件、40 场对话、3 对结婚、0 新生儿、0 案件，0 模型 token。事件具有概率，不能把测试夹具中的出生和案件算成自然发生。
- 另使用隔离场景验证出生、监禁、儿童缩放渲染及 390 × 844 手机全屏：没有页面脚本错误或横向溢出。截图见 `output/playwright/society-qa-prison-child.png`、`society-qa-family-case.png`、`society-qa-mobile.png`。主世界升级时保留原进度、记忆、预算，并保持暂停。

上述均不是持续真实模型效果或 token 实测；24 人场景的模型费用需在实际运行中重新测量。
