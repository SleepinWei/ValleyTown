# 全屏、光影与天气

> 2026-09-27 更新：离线补算功能已移除。后端重启从保存的游戏时间继续，旧存档的待补算时间自动清除；下文涉及离线补算的设计与验证记录仅描述旧版行为。

2026-09-27，基于大地图扩建版本。

## 使用

地图右上角「全屏观看」进入沉浸视野。浏览器支持时使用原生全屏；内嵌浏览器不允许原生全屏时，自动填满当前页面。Esc 或「退出全屏」返回，焦点回到入口按钮。全屏保留暂停 / 继续、区域导航、镜头控制、户外活动与对话框。

地图左下角显示当前天气、昼夜阶段与环境影响。右侧星光按钮切换电影调色、泛光、景深、云层、云影及雨线，不改变模拟中的天气或活动规则。遵循系统的“减少动态效果”设置；全局暂停时天气粒子不继续运动。

## Three.js HD-2D 渲染

- 已用 Three.js / WebGL 2 完整替换 Phaser。地面是带像素纹理的网格，山区有高度变化；房屋使用立体墙体、三角屋顶、窗框与烟囱，树木以实例化几何体绘制。
- 像素角色使用透明贴图平面，有行走帧并朝向镜头；建筑和树木通过深度缓冲自然遮挡角色。地面高亮标记和 DOM 标签便于追踪。
- 正交斜视镜头可以缩放、拖动、旋转、跟随角色；Raycaster 将点击映射到地形坐标，仍由原有世界规则校验碰撞和寻路。全域地图展示六个地区。
- 主方向光产生真实投影；天空光、环境光随昼夜调整。夜间窗户、路灯、营火发光，附近四个光源参与局部照明。
- EffectComposer 提供柔和泛光、基于场景深度的风格化景深、冷暖分离调色与暗角。复用场景通道的深度纹理，以镜头目标附近为清晰带，前后景渐进虚化；全域视角扩大清晰范围。景深采用 12 点采样并抑制前景轮廓外溢，不是物理相机散焦。
- 水面 Shader 根据距岸距离区分浅水与深水，生成像素亮纹、浅水焦散、岸边泡沫、晨昏反光及雨滴涟漪，并参与距离雾。36 片分层像素云共用三张程序纹理与一份平面几何体，地表着色器叠加缓慢漂移的云影；云层厚度、亮度与日照随天气调整。线段粒子表现雨，山地雨线从地形高度起落。减少动态效果或全局暂停时，云层、云影、天气粒子和水面动画停止；实际天气规则继续由服务器控制。
- 共用树木几何体并实例化，雨线数量上限 500，像素倍率上限 1.5，主灯使用 2048 阴影贴图，运行时逐帧更新，暂停时限频更新。窗口变化通过 ResizeObserver 同步画布与后处理尺寸。
- 卸载时释放几何体、材质、纹理、后处理和 WebGL 上下文。图形上下文暂时丢失时显示恢复提示；无法初始化 WebGL 2 时显示明确的重试入口。

风格采用“像素角色 + 立体场景 + 戏剧性灯光”的 HD-2D 方向，素材为程序生成，没有使用《八方旅人》的游戏素材。

## 天气与行动

天气按游戏时间每 4 小时评估一次，使用四天循环的确定性天气序列，涵盖晴朗、多云、细雨、大雾和雷雨。保存 / 恢复沿用同一序列，不因刷新随机改变天气。旧存档首次读取保留当前天气，下一时间段再自然变化。

| 天气 | 移动速度 | 户外体力倍率 | 行动影响 |
| --- | ---: | ---: | --- |
| 晴朗 | 100% | 1.0 | 正常活动 |
| 多云 | 100% | 1.0 | 正常活动，钓鱼成功率 +3 个百分点 |
| 细雨 | 88% | 1.2 | 钓鱼成功率 +12 个百分点；部分居民偏好避雨 |
| 大雾 | 78% | 1.1 | 暂停登山、打猎；钓鱼成功率 -5 个百分点 |
| 雷雨 | 70% | 1.35 | 暂停所有露天活动；居民优先前往附近建筑屋檐 |

露天活动在出发、抵达及运行中检查天气。天气突变导致活动中止时不会重复扣物资或发放奖励；已经开始消耗的物品不返还。雷雨中的河岸约定推迟，不因天气降低关系值。建筑仍使用门前 / 屋檐交互，没有新增独立室内地图。

Jev 接收当前天气、昼夜、能见度、移动速度、户外体力倍率与环境建议，并从符合天气规则的行动中选择。DeepSeek 接收同样环境信息，编制含天气备用安排的阶段计划。天气改变触发重新规划；过期规划不覆盖当前计划，晚到的行动在执行时重新验证天气。规则模式同样体现这些影响，并明确标注不是模型决策。

天气事件是公共信息，居民分别记录自己经历的天气；不会因此共享其他居民的私人记忆。天气和户外结算自身不消耗模型 token，重新规划与决策沿用现有模型预算机制。

## 连续时间与太阳轨迹

- 游戏时间保留小数分钟。渲染时间在相邻服务器快照之间逐帧插值（通常滞后一个快照，插值窗口最多 750 ms），不越过已收到的世界时间；消息停止时不会自行推进小镇。
- 太阳采用完整 24 小时的连续倾斜圆轨迹：06:00 东方地平线、12:00 最高点、18:00 西方地平线，午夜衔接无跳变。光照强度、晨昏暖色与太阳方向分别计算，正午附近高度仍持续变化。
- 太阳落到地平线以下后关闭直射光，独立的冷色月光渐入；灯光、水面和镜头色调共用同一插值时间。晨昏阶段名称只用于文字显示。
- 运行时逐帧刷新阴影，避免旧版 120 ms 更新间隔造成投影阶跃；暂停、恢复存档、切换世界和长时间断线重连以权威时间为准。
- 新增 5 项时间与光照测试，覆盖全天角速度、午夜和晨昏连续性、快照插值、乱序时间/存档恢复、暂停恢复及离线补算插值。当前共 46 项测试通过，生产构建通过。
