# Jev 决策追踪与对照实验

观察者视角，选中居民后点击「Jev 决策实验室」。设置里的「实时决策」也有入口。游玩快照不包含执行追踪、候选和实验输入。

## 实际行动追踪

本地代码产生合法候选，Jev 选择，游戏重新校验并提交行动。后台 DeepSeek 计划不是每次选择的前置依赖；移动、寻路和画面渲染仍由本地逻辑执行。

新增记录分别保留模型选项、置信度、完整候选标签、API 返回分数、最终采用的动作、拒绝或替换原因、执行时的活动，以及该次提交直接产生的事件。分数不是经过校准的现实发生概率。

- requesting：正在请求模型。
- deferred：暂停期间收到结果，等待继续后重新校验。
- applied：动作交给游戏执行。去找人不等于已经见面，提出邀请不等于对方接受。
- overridden：低置信度改为等待，或执行时雷雨改为避雨。
- rejected：版本、可用状态、距离、资源等前提已变化。
- failed：请求最终失败，或 HTTP 成功但返回内容不合法。
- interrupted：进程中断，不能确认结果。

排队计时从调度器首次看到角色可决策开始，直到其获得行动槽位。完整模型调用包含所有 HTTP 尝试、退避和响应校验。就绪到结果包含排队、模型调用以及暂停暂存时间；结果指提交或拒绝，不是走完路径。没有把 HTTP 耗时称为纯模型推理时间。

异步请求通过 AsyncLocalStorage 归属到一个逻辑决策；成功、失败和重试均关联原有 token 台账。近期统计按逻辑决策计数，不把重试当成额外成功决策。历史单次响应记录不补造追踪数据。规则演示不进入真实模型统计。

`action_traces` 保留记录。观察者快照提供近期记录；实验室读取最近 200 条。后台规划、家庭双向同意和对话各自的完整业务链不属于此次普通行动追踪范围，原有决定与台账仍保留。

## 情境和速度实验

先暂停并等待在途工作结束，切换「真实 Agent」模式。

输入来源：

- 默认「合成测试人物」：仅使用内置固定测试资料，不读取存档中的角色、人设、秘密或记忆。
- 「所选居民快照」：使用本人精简上下文，包括人设、私人动机、部分本人记忆。运行会将这些内容发送给所选模型的 API；界面明确显示这一点。其他居民的私人秘密不进入输入。

实验统一设置基线为晴天、精力 75、普通邻居。可改变为雷雨、低精力、高怨恨、亲密关系及邀请，也可重复相同情境检查波动。固定七种候选意图不随情境变化而增减，避免将本地候选过滤误当成模型适应能力。真实世界仍会先过滤不合法动作，再在执行时校验。

每轮包含基线和变化后情境。各轮交替两者顺序，每个模型最多一个请求在途，两条独立通道并行运行。使用同一冻结输入和候选；SHA-256 指纹便于核对。Jev 使用原生 Choice；DeepSeek 使用 JSON 选择，关闭思考，最多 64 输出 token。Jev 会额外返回原生分数，两种服务的协议包装不同，因此比较的是当前 API 配置在动作选择任务上的端到端服务性能，不是严格相同计算量的底层模型性能。

实验运行时冻结世界时钟，停发普通行动、对话和后台任务。实验不把选择提交到实际世界；结束后保持暂停。全局暂停和 金额池上限都会停止后续请求；在途请求继续结算。正常退出或异常重启期间有实验标记时保持暂停，游戏时间不因停机推进。

实验与真实世界共用各供应商的人民币金额池及 token 用量台账。停止、失败和中断也保存记录。重启时未确认完成的实验标记中断。恢复世界存档不会重置模型台账或实验历史。

## 指标口径

- 最终合法选择率：成功选择 / 已结算逻辑调用；包含最终失败，不包含未发出的取消项和中断项。
- 完整调用 P50/P95：含失败，含该次请求全部重试和校验，不含本批前方样本的排队。
- 成功调用 P50：单独列出，防止与全体分布混淆。
- 排队 P50 / 全程 P95：从批次入队计时；全程终点为合法选择返回或失败。实验没有实际游戏执行阶段。
- 每分钟有效决策：有效选择数 / 全部已结算调用时间总和 × 60 秒；表示单请求通道能力，不是 24 NPC 小镇吞吐实测。
- 已知 token：各次尝试已结算的输入和输出之和；未知用量保留预留额并单列。

界面不自动声称加速倍数。少量样本只验证链路；应增加重复次数并在不同时间重复采样，再评估长尾、失败率、语义选择及单位有效决策消耗。相同输入也可能有随机波动。

实验 JSON 包含输入、候选、指纹、逐次选择与请求台账，居民快照模式的导出同样含其私人上下文。

## API

本地会话认证沿用现有 HTTP 与 Worker 代理。

- `GET /api/decision-lab`：最近五次实验和 200 条行动追踪。
- `POST /api/decision-lab`：actorId、scenario、repeats（1–10）、paired、profile（synthetic / resident）。立即返回 ID，实验在 Worker 异步运行。
- `POST /api/decision-lab/stop`：全局暂停，停发后续请求。

## 验证

自动化覆盖候选与执行分离、天气替换、低置信度回退、暂停暂存、版本失效、HTTP 失败、非法返回、并发请求归属、相同实验输入、固定并发、全局暂停、金额池上限、重启保护和本地 API 认证。

首次居民快照真实验证（2026-09-27）：晴天与雷雨各一次，两种模型共四个逻辑请求，全部成功，合计 5,793 tokens。Jev 返回 work / shelter，耗时 3,615 / 4,711 ms；DeepSeek 返回 talk / shelter，耗时 4,976 / 2,884 ms。实验前后核对的居民、事件和时间一致。仅作接口与隔离验证，样本不足以证明速度优势。摘要保存于 `output/decision-lab-smoke.json`，未包含私有输入正文。
