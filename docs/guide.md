# 溪谷镇使用指南

[返回首页](../README.md) · [部署到 Supabase](browser-deployment.md) · [文档导航](README.md)

## 启动

安装 Node.js 22.13+，执行 `npm ci` 后用 `npm run dev` 启动静态开发服务器。生产版本执行 `npm run build`，把 `dist/` 部署到静态托管；`npm start` 仅预览构建产物。

默认规则演示无需密钥和后端服务。云存档与真实模型按[部署指南](browser-deployment.md)配置。

## 如何玩

- 地图扩展为 **240 × 180 格（原来的 9 倍）**，包含中心城区、南风海岸、云杉山地、镜湖湿地、鹿鸣林地和青禾运动公园。用区域按钮、全域地图、拖动和滚轮浏览；「跟随玩家」回到自己身边。
- 点击「出门探索」选择海钓 / 湖钓 / 河钓、慢跑、篮球、登山、打猎或休息；角色自动走到目的地后开始。钓鱼需要鱼竿与鱼饵，打猎需要猎弓与箭矢且仅白天开放。完成活动获得收获或技能经验，体力不足可在营地休息。装备与消耗品可在杂货铺补给。
- 点击道路或使用 WASD / 方向键移动；按 E 与近处居民交谈。点击居民或左侧名单查看资料。
- 选中居民后点击「人物故事」，回顾全部已保存经历、精彩转折与逐日记录；可选 AI 叙事、核对原始依据并导出 Markdown。详见 [人物故事说明](character-stories.md)。
- 点击「走近，聊一聊」自动跟随居民，抵达后打开输入框。模型生成回应时，游戏时间与移动同步等待；回应生成后也会出现在角色头顶气泡中。
- 在背包中送礼、去杂货铺购买物品；到花圃、河岸、作坊帮工。背包和交易有真实库存与金币转移。
- 公告板提供修桥、晚灯集市项目；可以贡献物品、邀约、表达心意、道歉或结束恋爱关系。NPC 会自行判断是否接受。
- 「观察者」查看私人记忆、秘密、关系数值与决策概率。「自由游玩」只返回玩家可以看见的信息。两种视角是本地管理员的界面选择，不是多用户权限系统。
- 运行设置可切换真实模型 / 规则演示、分别调整 DeepSeek / Jev 人民币上限、载入文档和恢复存档。顶部滑块设置 0.25×–6× 的目标速率（1× = 30 分钟 / 游戏日），并显示近 5 秒测得的实际倍率。

## 全屏与天气

地图右上角点击「全屏观看」，Esc 或退出按钮返回。全屏保留暂停、导航、户外活动和对话。星光按钮可关闭电影与天气特效；镜头支持旋转。

世界使用 Three.js：像素角色、真实 3D 建筑与树木、斜视镜头、泛光、轻微景深与遮挡、日照投影、晨昏渐变、夜间灯光以及晴朗 / 多云 / 细雨 / 大雾 / 雷雨。天气每 4 游戏小时评估一次，同时影响 Jev 的行动选择、DeepSeek 的阶段规划、移动和户外体力；雷雨优先避雨并延期河岸约会，大雾暂停登山和打猎，细雨有利钓鱼。详情见 [光影与天气说明](weather-and-rendering.md)。

## 保存、暂停与返回

模拟由浏览器 Web Worker 执行。点击「开始生活 / 继续模拟」后才推进；页面隐藏、关闭、刷新或长时间挂起后暂停，不补算离线时间。重新打开后继续保存的世界，但不会自动恢复付费模型调用。

IndexedDB 自动保存本机状态。关闭浏览器前可以点击地图下方保存按钮留一个手动检查点。请勿同时在多个标签页运行同一个存档；第二个页面会提示关闭已有页面。

登录后，每个账号拥有独立云存档，可见页面每 30 秒尝试自动同步。跨设备前在设置中点击「立即同步」。版本冲突会暂停模拟和同步，先导出本机备份，再选择云端版本；不自动覆盖或合并。

## 文档与记忆

在人物「记忆 / 秘密 → 编辑文档」中编辑人设、秘密、长期补充设定和当日记忆。保留 `document_id` 与 `base_revision` 头部；保存后立即生效，冲突不会覆盖当前版本。当日补充在下一游戏日退出短期上下文。

当前浏览器版本不直接扫描电脑上的 Markdown 文件。编辑内容随本机和云端存档保存，人物故事支持导出 Markdown；完整备份可以在设置中导出 JSON。

## 真实模型与预算

Jev 负责类型化行动与对白意图，DeepSeek 负责阶段规划和对白表达，本地规则验证并执行。日终默认摘录实际经历。规则演示始终标注「非模型」。

部署者在 Supabase Edge Function Secrets 配置供应商密钥，并在 `model_access` 给账号授予权限和云端硬额度。前端「设置 → 检查模型连接」确认就绪后，暂停、切换真实 Agent，再继续模拟。

页面中的两个人民币金额池是本机额外限制；Supabase 保有独立且不可通过读档或清理浏览器重置的云端账本。任一限制不足时拒绝新调用。关闭页面不能撤销已到达供应商的请求；无法确认结果时保留预留额度。

## 导入与备份

设置中可导出、导入 JSON。导入前暂停并等待模型任务结算；导入替换世界，但不会退回已有本地用量。访客与账号数据相互独立，可先导出访客备份，再登录导入。

浏览器数据清理会删除访客小镇和未同步数据。云端和导入文件上限均为 10 MB。旧 SQLite 存档使用[只读迁移工具](browser-deployment.md#迁移旧-sqlite-存档)导出；原有 Node 服务说明保留在[旧版指南](legacy-local-guide.md)。

## 验证与维护

```bash
npm test
npm run build
npm run check:simulation
```

测试包括规则、上下文隔离、浏览器生命周期、IndexedDB、模型代理以及 PostgreSQL 权限与预算。`check:simulation` 使用临时规则世界，不产生费用。

历史 `smoke:models` 和 `smoke:agent` 仍是 Node 供应商诊断脚本，会调用付费模型，使用后端环境变量并写入其本地账本；不是当前网页的启动步骤或云端代理验收。云部署验收方法见[部署指南](browser-deployment.md#验证)。
