# Jev 实时决策与角色气泡

候选动作由本地规则生成。DeepSeek 只负责较低频的阶段规划、日终反思和对白表达；不用等待 DeepSeek 生成候选列表。

## 当前执行路径

```text
本地每 100 ms 更新移动、碰撞、时钟、活动与天气
    ↓ 到达目的地 / 空闲 / 状态变化
本地筛选候选 → Jev Choice → 校验并执行动作

后台：DeepSeek 更新阶段计划与每日反思
对白：Jev 意图 → DeepSeek 短对白（关闭 thinking）→ Jev Noul 核验
      → 确认对白写入双方记忆 → 头顶气泡 / 对话框
浏览器：独立 requestAnimationFrame 绘制、插值与镜头更新
```

三个独立任务池：行动 6、对白 3、后台 2。原先所有任务共用 3 个名额，角色先规划再行动；现在后台规划不占用角色的行动忙碌标志，也不占用快速队列名额。即使某段文本请求很慢，其它居民仍可决策和行动。进入一段对话的两人等待自己的回应，其他居民不需要等它们。

- 空闲行动使用约 1.5 秒的最短调度间隔，并与游戏日速度换算；不会每帧调用模型。工作、休息、户外活动仍遵守各自持续时间，行走中继续本地寻路，不重复询问模型每一步往哪走。
- 快速上下文只包含本人简要人设、当前目标、缓存计划、天气、需求、库存、目标关系、4 条重要记忆和 4 条当日记忆；文本字段有长度界限。省去候选动作在请求 state 内的重复副本。完整记忆和文档仍保留，不因精简请求而删掉历史。
- 阶段规划和反思默认关闭 DeepSeek thinking，输出上限分别为 512 / 768 tokens。若确有更深推理需求，可设置 `DEEPSEEK_BACKGROUND_THINKING=true` 后重启；高层工作仍与行动队列分离。
- 普通对白输出上限 160 tokens，最终显示最多 240 字符。保留意图检查、表达校验和秘密披露条件，没有为了速度提前展示未核验草稿。
- 玩家聊天不再降低整个小镇时钟速度。输入等待按 180 秒运行中的真实时间判断，暂停时不计时。NPC 对话在生成中不会因为接口慢而被游戏时间直接掐掉；回复成功后续期。
- 在途模型失败仍明确标记为失败，并有重试间隔。没有把规则动作伪装成 Jev，也没有缓存复用需要双方同意的婚姻／育儿结果。

## 气泡

角色头顶显示已说出的对白，生成回应时显示省略号；支持玩家和 NPC 说话、镜头拖动 / 旋转、缩放和全屏。附近气泡会向上错开，最多显示 4 个；文字长度决定约 7–16 秒的显示期限，全局暂停时停留，新的发言替换旧发言。

观察者可以看 NPC 间对白；自由游玩只收到玩家参与的对话气泡。气泡来自服务端已经提交的发言，不从人物私有记忆或正在生成的草稿中取文本。规则演示明确标注演示对白。

## 验证与边界

- 自动测试覆盖慢规划不占行动名额、3 段慢对白不阻塞其它 Jev 行动、暂停结果延后提交、气泡隐私隔离、玩家聊天不再拖慢全镇、上下文缩减不改变完整记忆。
- 当前 24 人存档的上下文估算：平均 2,339 → 1,111 tokens，减少约 53%。这不含候选题目，不代表实际计费或接口响应耗时；结果保存于 `output/realtime-context-estimate.json`。
- 网络请求仍有实际服务端推理、网络往返及传输重试耗时。目前本机沿用既有 curl 传输配置，没有为了追求理论速度切回曾经握手失败的传输方案。
- 本次调度测试使用隔离规则世界和可控的延迟模型替身。另只读查看现有账本，最近 6 次成功 Jev 行动请求的单次耗时分别为 2348、1355、903、1195、2168、900 ms；该样本只包含成功尝试，不含排队和先前重试，不能当作稳定延迟承诺。
- 46 项自动测试通过，生产构建通过；浏览器验证头顶对白、旋转镜头、游玩视角隐藏 NPC 私有交谈、390 × 844 手机全屏，未发现页面脚本错误或横向溢出。截图在 `output/playwright/realtime-bubbles*.png`。
- 运行设置新增实时任务池占用与最近一次行动输入估算。

这一结构让画面和已有动作连续进行，减少大模型排队造成的停顿；若要每个角色每秒都得到一次新模型决策，还需要根据真实 Jev 延迟、限流和 token 吞吐实测调整，不能仅增加并发就保证达到。
