# 模拟性能实测（2026-09-27）

已落实「普通行动异步、关键节点同步」。本机真实 API 短测平均 **5.22×**，普通运行阶段的近 5 秒读数达到 **6×**；同步节点仍会降速。此结果是短样本，不代表全天稳定 6×。

## 实测

两个窗口均使用现有 24 人世界、真实模型、目标 6×，不跳过 Agent 决策。世界状态和网络状况随时间变化，属于运行现场的前后观测，不是同一存档的严格对照实验。

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 观测时长 | 55.30 秒 | 13.24 秒 |
| 游戏时间 / 现实时间折算倍率 | 0.31× | 5.22× |
| 等待 API 的采样点 | 41 / 46 | 1 / 14 |

新调度下，等待 API 指标仅表示关键节点的实际停等；普通异步请求不计为全镇等待。倍率使用整个观测窗口的游戏分钟增量 / 现实秒 / 0.8 计算，不使用滑块目标或前端动画速度。

后测原计划最多 75 秒，但达到预设 20 万 token 停测阈值后，在 13 秒结束；包括停测时仍在途的请求，最终结算 207,202 tokens。测试没有提高预算或清空用量，结束后恢复原来的 **暂停、2.75×** 设置。提速后每现实秒完成更多模型决策，token 消耗也随之加快。

该窗口成功 Jev 行动请求 88 次，延迟中位数 462 ms、P95 1,249 ms；另有 1 次约 5.2 秒的连接失败。此前最近 400 条账本中成功 Jev 行动中位数约 1,258 ms、P95 3,995 ms，并有较多约 5 秒的连接失败。样本不同，不能将全部改善归因于连接复用。

## 耗时点与改动

1. 原先任何 API 在途都会冻结全镇，基线约九成采样点在等待。现在已确定的走路、工作、休息继续，需要新决策的居民保持自己的忙碌锁。
2. 跨日／天气时段切换、约定到期及兑现、出生／司法结算、待回应的 NPC 会话到期，以及本人仍有请求在途的本地／户外活动结算前，停在边界前，暂缓自动派发新请求并排空当前决策，再越过节点。失败也能释放等待；故事整理不参与模拟屏障。结果提交仍校验版本、角色状态、距离和资源。
3. 本机从每次启动独立 curl 改为可复用连接的 Node fetch。保留瞬时网络错误后的单次 curl 回退，保持证书验证和请求用量记账。
4. 行动／对白／后台并发上限从 6 / 3 / 2 调整为 12 / 3 / 4；角色忙碌锁仍防止重复派发。
5. 用量查询缓存随预算变更、预留、结算和其他 SQLite 写入失效；预算预留仍在事务里读取实时总额。新增排序索引，已持久化的不可变事件不重复序列化，模型完成后的快照广播合并到 100 ms。

在独立数据库副本上的存储基准（100 次用量查询、20 次保存、50 次轨迹查询）：

| 单次操作均值 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 用量查询 | 5.04 ms | 0.12 ms |
| 保存世界 | 28.27 ms | 8.73 ms |
| 查询决策轨迹 | 20.80 ms | 4.32 ms |

离线时间、API 等待和长时间系统挂起均不产生需要补跑的时间债务。走路仍使用实际游戏时间，目标倍率仍是上限。

## 验证与记录

- 100 项自动测试通过，覆盖异步行动、9 类同步边界、等待期间不补入自动任务、失败恢复、暂停、预算、缓存失效与事件持久化。
- 生产构建通过。
- 三个游戏日的隔离规则模拟通过：3,601 个 tick、1,461 条事件、105 次会话，0 个真实模型 token。此项验证长时规则执行，不代表真实 API 吞吐。
- 原始数据：`output/performance-before-live.json`、`output/performance-after-live.json`、`output/performance-storage.json`、`output/performance-summary.json`。

剩余速度限制主要是关键节点所等待的最慢请求、网络失败与串行对白检查；目前没有以跳过决策或取消同步来保证恒定 6×。
