## 2. 已核实的接口

```text
POST https://api.typesafe.ai/v1/systemone
Authorization: Bearer <由后端环境变量提供>
Content-Type: application/json
```

请求顶层为 `model`、`state`、`questions`。state 可为文本、对象或数组；questions 是用户命名的问题映射。响应包含实际 `model`、`answers` 和 `usage.input_tokens / output_tokens`。

官方 Introduction 原文：

> No text generation, no parsing. You get typed values and probability distributions that your code can branch on, sort by, and route with.

因此它不是 Chat Completions 文本模型，不能让它直接撰写对白、故事、Markdown 日记或任意解释性 JSON。

| 原语 | 请求内容 | 响应字段与含义 |
|---|---|---|
| Choice | `type: choice`、instructions、criteria 选项映射 | choice、probabilities、confidence；最多 255 个选项 |
| Score | `type: score`、instructions、criteria 有序等级数组 | score、probabilities、confidence、legend；2–10 级，score 可为小数 |
| Noul | `type: noul`、instructions | noul，0–1；没有独立 confidence |

Score 是等级位置的概率加权平均；三档等级的范围是 0–2，不是自动归一到 0–1。Choice/Score confidence 描述概率分布集中程度，不是“答案一定正确”的保证。

同次请求中的问题针对同一个 state 独立并行评估，不能读取彼此答案。问题 ID 不发给底层模型；任务语义应写进 instructions，不能只靠 ID 暗示。可以合并独立问题减少网络往返，但额外问题仍产生输入 token。

## 3. 模型与计费快照

| 项目 | 官方页面当前值 |
|---|---|
| 固定模型 ID | `jev-1.13.0` |
| `jev-latest` / `jev-preview` | 当前都指向 `jev-1.13.0`；别名以后可变化 |
| 输入价格 | 每百万 token 0.042 美元（每十亿 42 美元） |
| 输出价格 | 免费 |
| 请求整体上下文 | state + 全部问题合计 64k token |
| 单问题上下文 | state + 最长单个问题不超过 32k token |
| 公开限流值 | 250,000 token/秒、1,200 请求/分钟，官方说明会动态调整 |
| 输入类型 | 文本、文本结构化对象或数组；不直接接收图像、音频、视频 |

复现演示优先固定版本并记录响应 model。实际账号限制与费用按运行时响应、供应商配置和账单核验；上述价格不是长期承诺。

Models 页面明确：英语是主要训练语言，其他语言包括 CJK 可以处理，但质量不完全相同，应以自有内容验证。小镇保持中文体验，需测试含蓄表达、反讽、拒绝、关系和秘密等场景。

## 4. 对设计的修正

- Jev：选择合法动作与目标、社交意图、披露片段，评估关系变化和事实判断。
- 运行时：构造合法候选、组合独立判断、处理低置信度、执行规则、写事件与事实日记。
- DeepSeek 宏观规划：长期目标、阶段安排、日终长文本反思。
- DeepSeek 文本表达：以隔离的上下文把 Jev 的既定意图写成自然语言；不能读取未获准的秘密或追加决策。
- 管理面板：原始类型化结果与系统解释分开，决策耗时与对白耗时分开；没有实测就不展示性能优势结论。

官网宣传中的特定任务性能倍数不作为本项目的验收指标；本轮核验的是能力与契约，并非中文小镇工作负载的实测结果。
