# 实现与验证记录

日期：2026-09-27。当前交付为本地可玩的 Agent 小镇首版，设计文件 `system-design-review.md` 保留审核时的目标范围；本文件记录实际实现。

最新更新：已切换 Three.js HD-2D 渲染，全屏、立体光影与天气决策已加入，30 项测试通过，见 [光影与天气说明](weather-and-rendering.md)。

同日后续扩建：地图面积增至 9 倍，加入海岸、山地、湖区、林地与运动公园，以及钓鱼、运动、打猎等活动。最新测试为 24 项通过，扩建后的三天规则运行和浏览器验收见 [大地图扩建说明](world-expansion.md)。下文保留首版验证数据。

## 已落地

- React 19 + Phaser 3 像素世界，8 位居民与玩家，鼠标寻路、键盘移动、中文输入对话、移动端布局。
- Jev 原生 Choice / Score / Noul 接入；高层阶段计划与日终反思使用 DeepSeek `deepseek-flash`。对白按 Jev 意图表达，再通过 Jev 校验；受限模板有明确来源标记。
- 独立私人上下文、人设、核心秘密和分级披露记录。参与者只获得实际发言；玩家快照不包含非参与者对话、私人记忆和秘密。
- 不对称好感、信任、吸引、怨怼、熟悉度；自主交谈、赠礼、邀约、告白、疏远，玩家送礼、帮工、交易、道歉、分手。赴约要求双方同时在河岸停留 15 游戏分钟。
- 真实物品转移、金币、工作产出、共同修桥和集市项目。
- SQLite 持久化；日记与长期记忆 Markdown；人设 / 秘密 / 长期补充 / 当日补充可编辑、定期载入、版本冲突保护、读档文档同步。
- 全局暂停、5–30 分钟/天、无天数上限离线补算、跨重启及读档保留的 token 账本、请求前预留、待核对调用保留额度。
- 限定本地访问；密钥仅后端配置；请求超时、一次重试、原生 TLS 传输回退。回退不关闭证书校验，curl 的密钥和请求正文仅通过标准输入传递。

## 真实模型测量

仅有限接口和单角色链路测试，未开展真实模型连续三日运行。

| 调用样本 | 输入 | 输出 | 单次成功请求耗时 |
| --- | ---: | ---: | ---: |
| Jev 中文邀请判断 | 400 | 39 | 879 ms |
| DeepSeek 短句表达 | 37 | 16 | 713 ms |
| Jev 下一步行动 | 1,993 | 106 | 1,667 ms |
| Jev 对话意图 | 1,528 | 70 | 822 ms |
| DeepSeek 对白表达 | 142 | 34 | 1,737 ms |
| Jev 对白校验 | 493 | 22 | 667 ms |
| DeepSeek 日终反思 | 299 | 1,988 | 9,947 ms |

最后一组“意图 → 表达 → 校验 → 反思”合计 **4,576 tokens**，其中三步对白链 **2,289 tokens**。表达未通过 Jev 校验时切换到受限模板，检查确认校验确实参与链路。DeepSeek 高层调用开启思考，输出用量包含服务报告的思考消耗；因此文本短不意味着输出 token 少。

截至本轮验证，主账本共 21 次请求尝试、实际已报告 **12,692 tokens**（8,172 输入 / 4,520 输出），另有 **10,350 tokens** 待核对预留。部分早期失败在连接阶段，但旧记录缺乏足够诊断，未擅自释放；新适配器可识别明确的连接前失败并释放对应预留。预留不是确认消费，实际账单以服务方为准。

原先的 3 日初估仍为约 360 万 tokens，含 25% 余量约 450 万；界面首轮上限 500 万，可修改。这些单次样本不足以替代三日实测，也不足以宣称 Jev 相较其他模型更快或更便宜。

## 首版边界

- 建筑提供门前交互，尚无独立室内场景；未实现完整农作物季节、战斗与大型经济系统。
- 长期记忆完整持久保存，决策只取有限重要记忆与近期经历；还没有语义向量检索、复杂传闻传播与完整因果溯源图。
- 观察者是本机管理视角，不是多用户授权系统。
- 独立保存的反思是角色的主观总结，仍可能出现模型误解；不作为世界事实自动执行。社会关系与 Noul 阈值需要更多中文样本校准。
- 当前网络曾多次在 TLS 握手时中断。原生传输和一次重试已接入，但持续可用性仍取决于网络与服务。
- 首版离线补算逐段推进并运行 Agent，未做大跨度叙事压缩；长时间离线可能需要较长补算时间，仍可随时暂停或等额度触顶暂停。
