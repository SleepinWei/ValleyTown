# 人民币金额池

DeepSeek / Jev 分别持有累计人民币上限，默认各 ¥10，可在运行设置中分别保存。0 表示关闭该池。余额互不借用；真实模拟需要的任一池不足时停止新调用并全局暂停，调高上限后手动继续。规则演示不受模型预算限制。实验室、角色故事、重试和校验都使用同一份持久账本，按实际调用的供应商扣款。

## 计价

2026-09-27 核对的官方价格：

| 模型 | 每百万输入 | 每百万缓存输入 | 每百万输出 |
| --- | --- | --- | --- |
| DeepSeek Flash | ¥2 | ¥0.04 | ¥8 |
| Jev 1.13.0 | $0.042 | $0.042 | 免费 |

来源：[DeepSeek 模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)、[Jev 模型](https://docs.typesafe.ai/models)。DeepSeek 用高峰价格保守估算，不推定空闲时段及节假日折扣。Jev 的美元价格使用保存的 USD/CNY 汇率折算，默认 7；用户可在设置中修改，系统不自动获取市场汇率。费用为本地估算，不代表供应商账户余额或正式账单。更换模型或供应商单价变化时需更新 `server/pricing.ts` 中价格版本。

派发前按未命中缓存的输入估算和输出余量原子预留金额，Jev 免费输出不占金额。供应商返回后按实际输入、输出及 DeepSeek 缓存命中字段计算费用；缓存明细缺失时按全部未命中估算。每次请求保存价格版本和汇率，之后修改汇率不改变历史费用或在途请求。金额在 SQLite 中以整数纳元保存，避免小额调用被四舍五入成零。费用估算与输入预估可能有误差，因此不能保证精确零超额。

明确未执行的失败释放预留；不确定是否执行、缺失或异常 usage、进程中断均保留预留并标记待核对。重试是独立调用，也需新的预留。已成功结算的调用不能重复扣款。

## 配置与迁移

新数据目录从 `DEEPSEEK_BUDGET_CNY=10`、`JEV_BUDGET_CNY=10`、`JEV_USD_CNY=7` 初始化；后续以 SQLite 中已保存设置为准，环境变量不覆盖界面修改。`TOKEN_LIMIT` 不再生效。

旧账本迁移不删除 token 记录：已知输入与输出按迁移价格折算；缓存折扣无法恢复，按未命中估算。旧预留只有总 token 数，按对应供应商最高单价保守折算。界面显示历史折算条数。旧 `paused_token_limit` 状态迁移成 `paused_budget_limit`，不会自动恢复运行。重启或恢复世界存档均不重置金额池。

`POST /api/control` 保存单池上限：`{"action":"limit","provider":"DeepSeek","value":10.50}`；Jev 使用 `"provider":"Jev"`。汇率更新为 `{"action":"exchange","value":7.0}`。金额限制为 0–1,000,000 元，最多两位小数；缺失供应商的旧接口请求会被拒绝。`usage.pools` 返回每个池的上限、已用、预留与可用金额；顶层 `used/input/output/reserved` 仍为 token 统计。
