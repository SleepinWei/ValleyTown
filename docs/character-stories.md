# 人物故事

选中居民，在人物资料中点击「人物故事」。已故居民仍可阅读档案。

打开即显示本地整理，无需模型调用：涵盖全部已保存时段的概览、值得回看的时刻、共同出现的人物和可逐日展开的完整记录。亮点优先考虑婚姻、出生、重大冲突、约定与关系变化，同时兼顾不同日期和事件类型。出现次数仅表示共同记录，不代表亲密程度。

## AI 叙事与原始依据

真实模型模式且配置 DeepSeek 后，点击「AI 写成故事」生成连贯叙事，并解释值得回看的部分。暂停时也可以手动生成；计入 DeepSeek 人民币金额池，继续记录 token 用量。相同记录复用缓存，更新记录后可以重新整理。关闭窗口不取消已经发出的任务；完成后重新打开可读取结果。失败时本地总结仍可阅读。

生成输入按整个时间跨度分段，每段保留事件统计和代表性证据；长历史不会简单截取最近几天。正文是摘要，不逐条复述所有事件；完整时间线与导出始终保留全部可用记录。每段叙事和亮点可查看原始依据。模型被要求区分事实、转述和反思，不补写缺失情节；仍建议核对证据。

## 视角与历史覆盖

- 观察者：居民本人的经历、记忆和反思，不读取其他居民的私有记忆。
- 自由游玩：公开事件及玩家参与的相关事件，不读取居民私人记忆。两种视角的模型结果分别缓存。
- 人设、秘密、编辑补充和未来计划不作为已发生的故事。
- 事件单独归档，不受首页最近 500 条事件的显示上限影响。人物存档保存事件索引，恢复存档后不会把被放弃时间线中的未来事件混入故事。
- 旧存档升级前的事件通过现存记忆和关联档案补回；已经没有记录的经历无法还原。界面会显示历史覆盖说明。

「导出」下载 Markdown，包含概览、已有 AI 叙事、亮点和逐日完整记录。

## 验证

自动测试覆盖历史超过 500 条、旧存档补回、视角隔离、去重、恢复存档、全时段输入压缩、异步任务、缓存、失败处理与 API / 模拟线程转发。桌面与 390px 手机浏览器已检查打开、生成、证据展开、导出和视角切换。浏览器验收在独立临时世界中使用模拟模型响应，没有为验收调用真实模型或修改主世界存档。
