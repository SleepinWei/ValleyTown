# 溪谷镇 · ValleyTown

一个在本地运行、有独立记忆的 Agent 小镇。React + Three.js 绘制 HD-2D 世界，Fastify + SQLite 驱动时间、规则、记忆与模型请求。

## 启动

需要 Node.js **22.13 或更新版本**（当前在 Node 26 验证）。

```bash
npm install
# 首次安装时，将 .env.example 复制为 .env，填写两个服务的密钥。
# 已配置好的工作区不要覆盖现有 .env。
npm run build
npm start
```

打开 http://127.0.0.1:3001 。新世界默认暂停，点击「开始生活」运行。开发使用 `npm run dev`，打开 Vite 显示的本地地址。

密钥只从后端 `.env` 读取，前端不持有。`.env`、世界数据库、私人文档和验证报告均已加入忽略列表。服务仅绑定 `127.0.0.1`。

## 如何玩

- 地图扩展为 **240 × 180 格（原来的 9 倍）**，包含中心城区、南风海岸、云杉山地、镜湖湿地、鹿鸣林地和青禾运动公园。用区域按钮、全域地图、拖动和滚轮浏览；「跟随玩家」回到自己身边。
- 点击「出门探索」选择海钓 / 湖钓 / 河钓、慢跑、篮球、登山、打猎或休息；角色自动走到目的地后开始。钓鱼需要鱼竿与鱼饵，打猎需要猎弓与箭矢且仅白天开放。完成活动获得收获或技能经验，体力不足可在营地休息。装备与消耗品可在杂货铺补给。
- 点击道路或使用 WASD / 方向键移动；按 E 与近处居民交谈。点击居民或左侧名单查看资料。
- 选中居民后点击「人物故事」，回顾全部已保存经历、精彩转折与逐日记录；可选 AI 叙事、核对原始依据并导出 Markdown。详见 [人物故事说明](docs/character-stories.md)。
- 点击「走近，聊一聊」自动跟随居民，抵达后打开输入框。模型生成回应时，游戏时间与移动同步等待；回应生成后也会出现在角色头顶气泡中。
- 在背包中送礼、去杂货铺购买物品；到花圃、河岸、作坊帮工。背包和交易有真实库存与金币转移。
- 公告板提供修桥、晚灯集市项目；可以贡献物品、邀约、表达心意、道歉或结束恋爱关系。NPC 会自行判断是否接受。
- 「观察者」查看私人记忆、秘密、关系数值与决策概率。「自由游玩」只返回玩家可以看见的信息。两种视角是本地管理员的界面选择，不是多用户权限系统。
- 运行设置可切换真实模型 / 规则演示、调整 token 上限、载入文档和恢复存档。顶部滑块设置 0.25×–6× 的目标速率（1× = 30 分钟 / 游戏日），并显示近 5 秒测得的实际倍率。

## 全屏与天气

地图右上角点击「全屏观看」，Esc 或退出按钮返回。全屏保留暂停、导航、户外活动和对话。星光按钮可关闭电影与天气特效；镜头支持旋转。

世界使用 Three.js：像素角色、真实 3D 建筑与树木、斜视镜头、泛光、轻微景深与遮挡、日照投影、晨昏渐变、夜间灯光以及晴朗 / 多云 / 细雨 / 大雾 / 雷雨。天气每 4 游戏小时评估一次，同时影响 Jev 的行动选择、DeepSeek 的阶段规划、移动和户外体力；雷雨优先避雨并延期河岸约会，大雾暂停登山和打猎，细雨有利钓鱼。详情见 [光影与天气说明](docs/weather-and-rendering.md)。

## 家庭、司法与独立模拟线程

新增 24 位成年居民、双方同意后的婚姻、概率育儿、凶案调查与监禁。点击左侧「家庭与司法」查看家庭和案件，地图「司法所 / 监狱」进入监狱视野。孩子有独立记忆与照护作息，已故居民保留档案，服刑者按监内作息行动。

行为、模型调用、寻路和存档运行在真正的 Node `worker_threads` 线程，浏览器 Three.js 绘制与服务主线程实时连接独立运行。现有存档自动备份并升级到 v3。具体概率、适用条件和当前范围见 [家庭、司法与模拟线程说明](docs/families-justice-workers.md)。

## 实时决策与头顶对白

Jev 快速行动、对白生成和后台规划使用独立任务池（12 / 3 / 4）。角色先用现有计划行动，DeepSeek 在后台更新规划，不再阻塞快速决策。头顶气泡显示已确认的对白，省略号表示正在生成回应，支持镜头跟随和全屏。观察者能看 NPC 间对白，游玩视角只显示玩家参与的交谈。

上下文精简、调度间隔、默认关闭后台 thinking、验证结果和性能边界见 [实时决策与气泡说明](docs/realtime-and-speech.md)。

## 模型分工

| 层次 | 模型 | 职责 |
| --- | --- | --- |
| 高频决策 | Jev `jev-1.13.0` | 原生 Choice 选行动、对白意图、社交回应；Score 评估交谈影响；Noul 校验表达 |
| 高层规划 | DeepSeek `deepseek-flash` | 阶段计划、每日反思 |
| 对白表达 | DeepSeek `deepseek-flash` | 把 Jev 已选意图写成中文；只接收经过筛选的公开事实和获准片段 |
| 世界执行 | 本地规则 | 寻路、碰撞、库存、关系变化、秘密条件、邀约履约、计时与记账 |

遇到本机 TLS 握手中断时，适配器最多重试一次并回退系统 curl。也可在 `.env` 设 `MODEL_HTTP_TRANSPORT=curl` 固定使用原生传输；需要系统安装 curl，证书验证保持开启。

Jev 的原生接口不生成自由文本。文字由 DeepSeek 表达，再交给 Jev 校验；不合格时使用明确标记的受限模板。规则演示不调用任何模型，界面会标注「非模型」。决策卡展示实际模型、选项概率、置信度、耗时和 token，不把概率当成正确率证明。

24 位成年居民（及后续出生的孩子）拥有自己的私人上下文。交谈仅把实际说出的句子写入接收者记忆，不复制对方的人设、秘密或完整记忆。秘密分层解锁，核心片段还要求高信任、共同经历和私密地点。普通转述保留为个人认知，而非世界事实。

## 记忆与文档

SQLite 是运行状态的权威来源，Markdown 提供编辑入口与可读投影：

```text
data/
  valleytown.sqlite
  editable/<角色 ID>/
    persona.md       # 人设
    secret.md        # 深层秘密
    notes.md         # 常驻长期补充设定
    today.md         # 导入当天有效的补充记忆
  memories/<角色 ID>/
    day-0001.md      # 当日实际经历的自动投影
    long-term.md     # 重要经历、承诺、日终反思，持续累积
  document-backups/  # 读档时保留尚未导入的外部编辑
```

在人物「记忆 / 秘密 → 编辑文档」中修改，或直接修改 `editable` 文件。保留 `document_id` 与 `base_revision` 头部。每 30 秒扫描一次，外部文本稳定两轮后载入，也可点击「立即载入」。版本冲突不覆盖现有内容；修改只进入该角色上下文。`today.md` 的补充在下一游戏日退出短期上下文，历史仍保留。自动生成的 `memories` 文件用于阅读；通过编辑入口补充认知，避免直接改写事件历史。

存档恢复会同步可编辑文档并生成新版本，外部尚未导入的文本备份至 `document-backups`。token 账本独立于世界存档，读档不能退回已消耗额度。

## 暂停、重启与预算

暂停会冻结游戏时钟、移动、自动决策、玩家行为，新模型请求停止。在途请求仍结算；返回的世界结果暂存，恢复时校验角色版本和会话轮次再应用。阅读、编辑文档和管理存档仍可使用。

后端持续运行时，即使关掉浏览器，世界也继续运行。后端停止后游戏时间不再推进，下次启动从最后保存的游戏时间继续，不补算停机时间，也不会为停机期间调用模型。退出前正在运行的世界重启后继续运行，已暂停的世界保持暂停。旧存档中尚未补算的离线时间会自动清除，已经发生的事件、记忆和 token 用量保留。游戏时间不需要追赶现实时间。目标倍率只是上限：普通行动、对白或后台模型请求期间，已确定的行走与活动继续，请求中的居民等待自己的新决策。跨日／天气时段切换、约定到期与兑现、出生／司法结算、待回应会话到期，以及仍有本人请求在途的本地／户外活动结算前，游戏时钟停在边界之前，停止自动派发新任务，等待现有请求结算再推进；提交时仍校验角色状态、版本与资源。故事整理不阻塞模拟。等待时间不积累也不补跑，失败请求按现有策略退避。走路按游戏分钟推进，晴天每游戏分钟 6.25 格，天气倍率仍生效。实际倍率 = 近 5 秒推进的游戏分钟 / 现实秒 / 0.8，包含 API 等待时间；暂停时显示 0。长时间系统挂起不推进游戏。

默认累计上限为 **5,000,000 tokens**，可在界面修改。Jev 与 DeepSeek 的输入、输出、重试和校验统一计入；发出前预留额度，返回后按 `usage` 结算。余额不足以预留下一次调用也会提前暂停。连接建立前的明确失败释放预留；可能已到服务端但用量未知的调用保留预留。进程中断和读档不清空账本。

原先 **8 人**版本的 3 游戏日设计初估是 **约 360 万，含 25% 余量约 450 万 tokens**；尚未完成真实模型连续 3 日实测，不能把规则模式三天报告当作模型用量。24 人及家庭事件会增加请求与上下文，旧估算不再代表当前版本；仍按实际账本和上限暂停。

## 验证与维护

```bash
npm test                 # 核心规则、隔离、预算、暂停、文档与 API 验证
npm run build            # TypeScript 检查与前端生产构建
npm run check:simulation # 临时规则世界加速运行三个游戏日，无模型费用
# 下列检查会调用真实模型；先暂停服务并等待所有请求结束，或停止服务：
npm run smoke:models     # 各一次小接口验证，可追加 -- deepseek / -- jev
npm run smoke:agent      # 临时世界中的规划、决策、对白校验、反思；计入主账本
```

报告位于 `output/`，设计与人物内容位于 `docs/`。数据库处于 WAL 模式；备份整个 `data` 目录前先停止服务，避免只复制主文件遗漏未合并事务。

大地图的区域、活动规则、旧存档迁移和验收记录见 [大地图扩建说明](docs/world-expansion.md)。

首版聚焦可玩的 Agent 社交与观察闭环。地图使用程序绘制的原创像素素材；建筑目前提供门前交互，尚未制作独立室内地图、完整种植季节系统或战斗。置信度阈值、中文质量和长期社交平衡仍需在持续真实运行中校准。

观察者视角新增「Jev 决策实验室」：查看模型选择与游戏实际执行、排队和重试耗时，运行固定候选的情境实验与 Jev / DeepSeek 对照。默认使用合成测试人物；也可明确选择含本人私有上下文的居民快照。实验共享 token 预算，冻结世界并在完成后保持暂停。详见 [决策实验室说明](docs/decision-lab.md)。

动作系统现在使用预定义注册表，按位置、身份、资源与事件生成候选。DeepSeek 改为每日首次规划，加上 Jev 主动选择的有限重规划；日终默认摘录真实经历，减少持续文本调用。实验室的「动作与规划」页显示当前候选和调用分工。详见 [动作库与按需规划](docs/action-policy.md)。
